# Security policy

## Scope

This repository contains the source of a static website served by GitHub Pages. There is no server-side code, no database, no user accounts and no form handling.

## Reporting a vulnerability

If you believe you have found a security issue in this website or repository, please contact the maintainer through the GitHub profile [github.com/EdisonBujupi](https://github.com/EdisonBujupi).

Please do not include exploit details in a public issue. Describe the affected page or file, the steps to reproduce the issue and its possible impact. Reports are reviewed as soon as possible.
